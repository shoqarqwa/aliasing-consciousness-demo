# Aliasing in Consciousness – Interactive Demo

This repository contains an interactive HTML demo accompanying the paper:

**Aliasing in Consciousness: How Coarse Sampling Produces Drama and How Presence Dissolves It**  
DOI: https://doi.org/10.5281/zenodo.19140110

The demo is designed to provide an intuitive visualization of how coarse temporal sampling and precision gain may shape perceived experiential “drama” across different perceptual states.

**Best viewed on desktop.**
